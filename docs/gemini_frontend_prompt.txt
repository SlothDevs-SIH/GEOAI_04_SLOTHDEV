1. THE PRODUCT IN ONE PAGE
--------------------------------------------------------------------------------
GEOAI 04 shows what REALLY changed on the ground between two satellite images, and filters out false alarms (seasonal crops, lighting, clouds, radar speckle). The user sees a before/after swipe map with coloured change polygons ranked by severity, a one-line reason for every change, an impact summary, and exports for GIS.

Who uses it: district officers, planners and disaster teams in India, on laptops and phones, sometimes with poor network. Therefore: fast, calm, readable outdoors, works offline for the demo scenes, and never overstates what it knows.

The five screens: Scenes (home), Result (swipe map), Analyse (any area, upload, radar), Accuracy (measured numbers), About (how it works, tech stack, limits).

Tone of copy: plain English, short sentences, no jargon without a one-line explanation. Honest: say what is measured and what is not.

9. EXACT COPY AND FORMATS (use these strings verbatim; keep them in strings.ts for later translation)
--------------------------------------------------------------------------------
Tier labels: Critical, High, Medium, Low.
Change-type labels: water_gain "New water / flooding"; water_loss "Water receded"; built_up_gain "New construction"; vegetation_loss "Vegetation cleared"; vegetation_gain "Vegetation growth"; other "Other change".
Dropped-by-rule labels: cloud "under cloud or shadow"; seasonal "seasonal / lighting change"; not_in_preset "change type not relevant here"; speckle "speckle (thinner than 3 px)"; min_area "smaller than the minimum area"; permanent_water "permanent water (rivers, lakes)"; speckle_morphology "radar speckle"; below_min_area "smaller than the minimum area"; persistence "seen in only one image".
Kind chips: flood "Flood - radar"; encroachment "Encroachment"; control "False-alarm control"; regional "Regional check".
Number format: Indian grouping everywhere (Intl.NumberFormat "en-IN"): 2,185. Missing value: the en dash for table cells, the word "unknown" in the Impact panel, never 0.
Area format: below 10,000 m2 show "<n> m2" (superscript 2), otherwise hectares: >= 100 ha no decimals, 10 to 100 ha one decimal, below 10 ha two decimals ("1.25 ha"). Coordinates: 6 decimals. Percent: round to whole numbers.
Offline: badge "Offline - demo data"; Analyse offline title "Live analysis is offline"; body "The analysis server is not reachable (it may be waking up; try again in a minute). The demo scenes work without it." with the link "Open the demo scenes". When no API is configured: "(no API is configured for this deployment)".
About - four steps:
  1 - Align: "Read the before and after images, put them on one grid and check they line up (a 1-2 pixel shift makes every edge look like change)."
  2 - Detect: "Optical (Sentinel-2): vegetation, built-up and water indices plus total change. Radar (Sentinel-1): flood water is dark; one threshold per flood event, then region growing."
  3 - Filter false alarms: "Drop cloud, seasonal crop and lighting changes, radar speckle, permanent rivers and tiny specks. Every rule counts what it removed."
  4 - Explain and rank: "Each remaining change becomes a polygon with its area, confidence, a plain-language reason, a location and a severity tier, ready for QGIS."
About - tech stack rows (Layer | What we use | Status):
  Web app | React 19, Vite, TypeScript, Tailwind CSS, MapLibre GL (before/after swipe map), Zustand, React Router (the current web build) | Used now
  Cross-platform app | React Native with Expo and React Native Web (this app) | In progress
  Web tests | Vitest, Testing Library, Playwright; GitHub Actions CI | Used now
  Engine | Python 3.11, Rasterio / GDAL, GeoPandas, Shapely, NumPy, SciPy, scikit-image, scikit-learn | Used now
  API | FastAPI, Uvicorn; any-area fetch from Sentinel-2; Docker | Used now
  Radar flood mode | Sentinel-1 (VV/VH), event threshold + region growing, evaluated on Sen1Floods11 | Used now
  Deep learning | PyTorch (Siamese U-Net trained on OSCD), ONNX Runtime for serving | In progress
  High-res mode | BIT Siamese transformer, evaluated on LEVIR-CD | In progress
  Data | Sentinel-2 L2A, Sentinel-1, ESA WorldCover, JRC water, OpenStreetMap, OSCD, LEVIR-CD, Sen1Floods11 | Used now
